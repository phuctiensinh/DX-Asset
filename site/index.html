DX-Asset

Nền tảng mã nguồn mở quản lý vòng đời tài sản số doanh nghiệp: cấp phát, báo sự cố, bảo trì, lịch sử, dashboard, phân tích quy trình và trợ lý AI chạy cục bộ bằng Ollama.

Giới thiệu

DX-Asset giúp doanh nghiệp quản lý tập trung tài sản và thiết bị nội bộ (laptop, máy tính, màn hình, máy in, thiết bị mạng…) thay cho Excel, giấy tờ và tin nhắn: biết thiết bị đang ở đâu, ai đang giữ, đã bàn giao và sửa chữa những lần nào.

Luồng nghiệp vụ chính

Tạo tài sản & mã QR→Cấp phát cho nhân viên→Báo sự cố kèm ảnh→IT xử lý & bảo trì→Lưu lịch sử→Dashboard & phân tích

Tính năng theo 4 không gian DX-OS

H — Con người

  • 4 vai trò: ADMIN, IT_ASSET_MANAGER, MANAGER, EMPLOYEE
  • Đăng nhập/đăng ký qua Keycloak
  • Quyền được kiểm tra ở backend
  • Quản lý người dùng, phòng ban

P — Quy trình

  • Thêm, sửa, tìm, lọc, thanh lý tài sản (không xóa lịch sử)
  • Cấp phát, thu hồi, chuyển giao
  • Báo sự cố kèm ảnh, phân công kỹ thuật viên
  • Phiếu bảo trì, ghi chi phí sửa chữa

D — Dữ liệu

  • Dashboard theo trạng thái, sự cố, phòng ban
  • Phân tích tài sản: điểm sức khỏe, mức rủi ro
  • Phân tích quy trình (Process Mining)
  • Mô phỏng "nếu… thì…" (chỉ tham khảo)

I — Trí tuệ nhân tạo

  • AI chạy cục bộ bằng Ollama
  • Chỉ gợi ý và diễn giải, con người quyết định
  • Có phương án dự phòng khi AI không sẵn sàng

AI chạy cục bộ (Ollama)

AI dùng model nguồn mở qwen2.5:3b chạy ngay trên máy chủ, không gửi dữ liệu ra ngoài và không cần API key. Nguyên tắc: Backend tính số liệu, AI chỉ diễn giải và gợi ý.

Ollama không truy cập cơ sở dữ liệu, không chạy SQL, không vượt qua phân quyền và không thay đổi dữ liệu. Khi Ollama tắt hoặc chậm, hệ thống tự dùng kết quả dự phòng theo quy tắc và ghi rõ nguồn trên giao diện.

Cài đặt bằng Docker (khuyến nghị)

Yêu cầu: Windows 10 (21H2+)/11, macOS 12+ hoặc Ubuntu 22.04/Debian 12+; RAM trống ~6 GB, ổ đĩa trống ~10 GB; có Internet ở lần cài đầu. Không cần cài Python, Node.js hay PostgreSQL.

Bước 0 — Cài Git và Docker (một lần)

Windows 10/11

Mở PowerShell bằng quyền Administrator và chạy:

wsl --install
winget install -e --id Git.Git --accept-package-agreements --accept-source-agreements
winget install -e --id Docker.DockerDesktop --accept-package-agreements --accept-source-agreements

Khởi động lại máy, mở Docker Desktop, bấm Accept và đợi hiện Engine running.

macOS

Cài Homebrew theo hướng dẫn tại brew.sh, sau đó:

brew install git
brew install --cask docker
open -a Docker
Ubuntu / Debian 
sudo apt-get update && sudo apt-get install -y git curl
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER

Đăng xuất và đăng nhập lại sau lệnh cuối.

Bước 1 — Tải mã nguồn

git clone https://github.com/phuctiensinh/DX-Asset.git
cd DX-Asset

Bước 2 — Tạo file cấu hình

# Windows (PowerShell)
Copy-Item .env.example .env
# macOS / Linux
cp .env.example .env

Giữ nguyên giá trị mặc định là chạy được trên máy cá nhân. Khi triển khai thật, bắt buộc đổi SECRET_KEY, POSTGRES_PASSWORD, KEYCLOAK_ADMIN_PASSWORD.

Bước 3 — Build và khởi động

docker compose up -d --build

Lần đầu mất khoảng 5–15 phút. Model AI (~1.9 GB) được tải ngầm sau đó; trong lúc chờ, các tính năng AI tạm dùng chế độ dự phòng.

Bước 4 — Kiểm tra

docker compose ps -a

dx_asset_postgres, dx_asset_keycloak, dx_asset_seaweedfs, dx_asset_ollama ở trạng thái healthy; dx_asset_backend, dx_asset_frontend ở trạng thái Up; dx_asset_ollama_pull là Exited (0) (bình thường).

Bước 5 — Mở ứng dụng

Dịch vụĐịa chỉ
Ứng dụng webhttp://localhost:3000
Tài liệu API (Swagger)http://localhost:8000/docs
Trang quản trị Keycloakhttp://localhost:8080
Luôn truy cập bằng localhost, không dùng 127.0.0.1 hay IP máy, nếu không sẽ bị lỗi đăng nhập 401.

Máy có card NVIDIA có thể bật GPU cho AI:

docker compose -f docker-compose.yml -f docker-compose.gpu.yml up -d --build

Hướng dẫn chạy dev local (backend, frontend chạy trực tiếp trên máy) xem trong README.

Tài khoản đăng nhập

  • Tại trang đăng nhập, bấm Đăng ký tài khoản mới; tài khoản mới có vai trò Nhân viên.
  • Hệ thống chỉ có một tài khoản ADMIN (chủ hệ thống); ADMIN đổi vai trò cho người dùng khác tại trang Người dùng. Chi tiết xem README.
  • Mỗi máy có Keycloak riêng nên tài khoản không dùng chung giữa các máy.

Sử dụng nhanh

  1. Tài sản: thêm tài sản, xem chi tiết và mã QR, tìm kiếm, lọc theo trạng thái.
  2. Cấp phát: cấp tài sản cho nhân viên, thu hồi hoặc chuyển giao.
  3. Sự cố: nhân viên báo lỗi kèm ảnh; IT phân công, cập nhật trạng thái.
  4. Bảo trì: lập phiếu, bắt đầu/hoàn thành, ghi chi phí.
  5. Tổng quan, Phân tích tài sản, Phân tích quy trình: xem số liệu (ADMIN, IT_ASSET_MANAGER, MANAGER).
  6. Trợ lý AI: hỏi bằng tiếng Việt, ví dụ "Tài sản nào chưa được cấp phát?".
